# Working on APEX

Build complete, small verticals through the real entry point. Reuse reviewed APEXAI code with its source pin and explicit limitations. Keep production state untouched unless the task actually authorizes and configures that operation.

- Tests must show real readers and resulting behavior, not just imports or labels.
- Preserve event time, completion time, availability and retrieval time as separate concepts. Never invent a measured receipt.
- Missing market data is not zero. Simulation output is not calibrated probability. A descriptive score is not an admission decision.
- Run `python -m pytest -q`, the real `apex demo` command and `apex verify` after changes to this connected path. Name any unexecuted gate.
- Do not weaken thresholds to manufacture trades. A synthetic control may deliberately exercise a trade, but must remain unmistakably synthetic.
- Do not introduce broker execution into the offline replay module. Live paper needs its own reviewed adapter, position recovery, account contract and commissioning evidence.
- Logs must never contain credentials. Raw licensed captures belong outside Git, in ignored `data/` and `runs/`, with protected durable storage configured for operations.
- Use unique run directories. Keep failed artifacts; do not replace a failed run with a successful rerun under the same identity.
- A hash chain is internal consistency, not independent authentication. State verification scope precisely.
